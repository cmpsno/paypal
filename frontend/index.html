Offline ML model — Zenodo data only, never PayPal

A logistic regression trained offline on the Zenodo dataset (57,394 rows, 111 fraud). It scores dataset rows — amount plus 28 PCA signals (v1–v28). It never scores a live PayPal transaction: a live transaction has no v1–v28 features. The rules engine above is the live decision-maker; this is the evaluated offline baseline.

Monitoring — the feedback loop

Every prediction is logged with its model version, score, decision, and reasons — logging never changes a score. True precision/recall can't be measured until someone confirms what was actually fraud, which arrives days or weeks later. Drift is the early warning: recent predictions compared against all-time, watchable before any outcomes arrive. Storage is in-memory and resets when the server restarts.
